# Django Code Generator

A **Python-based code generator** designed to automate the creation of **CRUD (Create, Read, Update, Delete)** applications in Django.
This tool dynamically generates **models, forms, views, URLs, and templates** for Django projects, significantly reducing repetitive coding tasks and speeding up development.

---

## 🚀 Features

* Generate **Django models** from user input or pre-defined data structures.
* Automatically create **forms** for generated models.
* Build **views** for CRUD operations (Create, List, Update, Delete).
* Generate **URL routes** for all views.
* Create **basic Bootstrap-ready templates** for CRUD pages.
* Option to append generated code to existing Django files instead of overwriting them.
* Interactive CLI for gathering required data.
* Extendable for future integration with **UI-based input collection**.
